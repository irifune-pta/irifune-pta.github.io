# 入船小学校 PTA 役員募集サイト

令和9年度の本部役員・社会福祉協議会推進委員の募集ページです。
配布プリント（`令和9年度PTA役員募集_呼びかけ_ポップ版.docx`）と同じ内容を、
スマートフォンで読める形にしたものです。

公開予定URL: https://irifune-pta.github.io/recruit/

---

## 📁 ファイル構成

```
recruit/
├── index.html        ← ページ本体（基本的に触らない）
├── config.js         ← 年度・URL・数字（★ここだけ編集すればOK）
├── README.md         ← このファイル
└── images/
    └── school-emblem.png   ← 校章
```

安全活動サイト（https://irifune-pta.github.io/ ）と**同じ仕組み・同じデザイン**です。
編集のしかたも同じなので、安全活動サイトのREADMEも参考になります。

---

## 🚀 公開のしかた

安全活動サイトのリポジトリ `irifune-pta/irifune-pta.github.io` に、
この `役員募集サイト` フォルダを **`recruit` という名前で** 追加します。

1. https://github.com/irifune-pta/irifune-pta.github.io を開く
2. 「Add file」→「Upload files」
3. `役員募集サイト` フォルダの中身をドラッグ&ドロップし、
   アップロード先のパスを `recruit/` にする
   （フォルダごとドラッグする場合は、事前にフォルダ名を `recruit` にリネームしておく）
4. 「Commit changes」

1〜2分で https://irifune-pta.github.io/recruit/ に反映されます。

**新しくリポジトリを作る必要はありません。** 安全活動サイトとは別のURLになるので、
それぞれ独立したサイトとして案内できます。

## 📝 まだ決まっていない項目について

`config.js` の **★マークが付いた項目** が未確定です。
ただし **空欄のまま、または【 】が残ったままの項目は、ページ側で自動的に非表示になります。**
書きかけの【 】が保護者に見えることはないので、**この状態のまま公開しても問題ありません。**

決まり次第 `config.js` に書き足せば、その部分が自然に現れます。

| 項目 | 内容 | 未記入のときの見え方 |
|------|------|---------------------|
| `formUrl` | 応募フォームのURL | ボタンが「フォームは準備中です」（押せない）／メール受付の案内は出る |
| `qrImageUrl` | QRコード画像のパス | QRの枠ごと消える |
| `contactPerson` | 担当者名・連絡方法 | 行ごと消える |
| `meetingTime` | 会議の時間帯 | 「開催は〜です。」の一文が消える |
| `meetingOnline` | オンライン参加の可否 | 「オンライン参加も〜。」の一文が消える |
| `reducedWorkload` | 今年度やめたこと・減らしたこと | その一文が消える |
| `voice1Text` / `voice2Text` | 経験者の声 | 両方空なら「やってみた人の話」セクションごと消える |

**経験者の声は、よかったことと大変だったことを両方入れてください。**
良い面だけだと読んだ人に信用されません。

### 公開してすぐ効くのは、応募フォームのURLです

いまはフォームボタンが押せない状態なので、**URLが決まるまでは保護者にこのページを案内しないでください。**
`config.js` の `formUrl` に貼るだけでボタンが有効になります。

## ✏️ よくある編集

### 応募フォームのURLが決まった

`config.js` の `formUrl` に貼り付けるだけです。
ボタンが自動的に有効になり、文言も「応募フォームを開く」に変わります。

```javascript
formUrl: "https://forms.gle/XXXXXXXX",
```

### QRコードを載せたい

1. QRコード画像を `images/qr.png` として保存
2. `config.js` を編集

```javascript
qrImageUrl: "images/qr.png",
```

### 受付期間を変えたい

`config.js` の `applyPeriod` を書き換えます。ページ内2か所（ヒーローと応募欄）に自動反映されます。

### 来年度も使いまわしたい

`config.js` の `targetYear` `issueDate` `applyPeriod` `deadlineDate` `formUrl` を新年度の値に
書き換えれば、そのまま使えます。あわせて「正直に、いまの状況もお伝えします」の
数字（`index.html` 内の `class="honest"` の部分）を最新の実績に更新してください。

## ⚠️ 内容を変えるときの注意

このページの文面は、応募が集まらない状態を変えるために意図的にこう書いています。
編集するときは、次の点を崩さないでください。

- **義務系の文言を書かない。** 「1児童につき2回のご協力を」のような表現は、
  実態が任意なのに義務に見えるため、逆効果です。
- **「割り当て・くじ引きはありません。手挙げ制です」を最初に出す。**
  指名される恐怖がある限り、そもそも読まれません。
- **メリットを抽象語で書かない。** 「子どもたちの笑顔のために」は動機になりません。
- **負担は数字で書き、絶対に盛らない。** 実績にない回数を書くと、
  入った人が「話が違う」となって翌年の応募が消えます。
- **免除規定の話は書かない。** 「免除されていない人には義務がある」と読まれます。
- **応募の3択（①やってみます ②話を聞いてから決めたい ③単発の手伝い）を崩さない。**
  ②が最大の受け皿なので、目立たせたまま残してください。

## 📋 掲載している人数の根拠

役職の人数は **PTA会則 第7条**（令和7年度修正版）に合わせています。

| 役職 | 会則の定数 |
|------|-----------|
| 会長 | 1名 |
| 副会長 | 4名以上（保護者3以上・教職員1） |
| 書記 | 2名 |
| 会計 | 2名 |
| 会計監査 | 3名（保護者2・教職員1） |
| 社会福祉協議会推進委員 | 1名（任期2年） |

合計12名が「会則の定数」です。

**人数を変えるには会則の改正が必要です。** 会則の改廃は総会の議決事項で（第8条）、
書面決議では**意思表明者の3分の2以上**の同意が必要になります。
つまり定数を変えたい場合は、4月の総会に間に合うよう逆算して議案を準備することになります。

なお **会計監査は「本部役員経験者から選考委員会が選考する」**（第18条）と定められているため、
一般の保護者に向けて広く募集する役ではありません。ページ上でもその旨を明記しています。

## 🔒 検索避けについて

安全活動サイトと同じく、`index.html` に `noindex` を入れてあります。
リポジトリ直下の `robots.txt` も効くので、検索エンジンには載りません。
保護者にはURLまたはQRコードで直接案内してください。

リポジトリは公開設定です。**氏名・電話番号などの個人情報は書かないでください。**
応募内容はGoogleフォーム側に入るので、このサイトには個人情報を持たせない設計にしています。
